# Интерактивное меню кафе (V2)

Улучшенная версия учебного проекта.

### Что нового в V2:
1.  **Калорийность:** Теперь на каждом блюде отображается его энергетическая ценность.
2.  **Обновленный состав:** Из ролла "Калифорния" удалено авокадо.
3.  **Оптимизация кода:** Комментарии стали короче, а логика фильтрации — лаконичнее.

### Структура проекта:
*   `index.html` — основная разметка.
*   `styles.css` — стили и оформление (добавлены бейджи калорий).
*   `script.js` — данные о блюдах и логика работы.

### Как запустить:
Просто откройте `index.html` в браузере.
