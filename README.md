# Интерактивное меню кафе (V3)

Финальная учебная версия проекта с корзиной.

### Что нового в V3:
1.  **Корзина заказов:** Появилась возможность добавлять и удалять товары, а также изменять их количество.
2.  **Уведомления:** Всплывающие подсказки (Toast) при добавлении блюда.
3.  **Рефакторинг:** Код стал более структурированным, используется современный подход к управлению элементами (DOM) и событиями.
4.  **Счетчики:** Автоматический пересчет итоговой суммы и количества товаров в реальном времени.

### Структура проекта:
*   `index.html` — разметка с контейнером для меню и модальным окном корзины.
*   `styles.css` — стили оформления, адаптивность и анимации корзины.
*   `script.js` — база данных, логика корзины и управление интерфейсом.

### Как запустить:
Просто откройте `index.html` в браузере.
